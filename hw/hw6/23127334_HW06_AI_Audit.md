# HW06 — AI Audit Verdict for 120 API Test Cases

Nguồn: `23127334_HW06_API_TestCases.xlsx`

## Quy ước đánh giá

- **VALID**: mục tiêu rõ, dữ liệu kiểm thử phù hợp và oracle đủ cụ thể để quyết định pass/fail.
- **INVALID**: mục tiêu hoặc oracle đang khẳng định một hành vi không có cơ sở, sai phạm vi hoặc có khả năng dẫn đến kết luận sai.
- **INCOMPLETE**: ý tưởng kiểm thử có giá trị nhưng cần chốt contract, boundary, status code hoặc tách lại phạm vi trước khi chấp nhận.

Đây là audit chất lượng test case **as-written**, không phải kết quả thực thi SUT. Workbook không kèm toàn văn FR/SEC, vì vậy các oracle tự đặt boundary hoặc cho phép nhiều status code được đánh dấu cần bổ sung đặc tả.

## Các correction cần ưu tiên

1. Chốt một status code duy nhất cho duplicate, usage-limit, auth failure, media type và referential-integrity cases.
2. Dẫn nguồn cho các boundary tự đặt: name length 1/255, Unicode/emoji policy, price precision và maximum value.
3. Với SQLi/XSS payload, oracle chính nên là **không injection/không execution/không mutation ngoài ý muốn**; việc API accept hay reject phải theo contract, không tự ép 200.
4. Tách UI stored-XSS verification khỏi API functional test để scope và evidence hữu hạn.
5. Định nghĩa rounding policy cho discount trước khi dùng số tiền tạo kết quả phân số.
